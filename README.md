# 灯塔漂流瓶

把一句心里话放进瓶子，灯塔会让它出海，再把回音送回来。这是一个很小的后端，用来做技术面试里的工程排错。请先跑起来，对照下面的预期看页面，再改代码。

## 修好后要同时满足

- 瓶子出海大约两秒，然后状态变为「已归来」，并停在那里。
- 每只瓶子只出海一次。出海记录只有一行。
- 回音里要包含你写下的心里话。心里话本身保持原样。

## 怎么跑

本机需要 Docker。在本目录执行：

```bash
docker compose up --build
```

浏览器打开 [http://localhost:8080](http://localhost:8080)，写上署名和心里话，投入海里，看十几秒。

数据在内存里，重启后瓶子会清空。
